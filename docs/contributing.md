# Contributing to DevPantry

Thank you for your interest in contributing to DevPantry!

As an open-source project, we welcome contributions, whether they are bug reports, feature requests, documentation improvements, or code contributions.

## Local Development

```bash
# Clone the repository
git clone https://github.com/allwin-antony/devpantry.git
cd devpantry

# Install dependencies
npm install

# Start local development server
npm run dev
```

For more details on the architecture and project structure, please read the [Architecture Guide](./architecture.md).
