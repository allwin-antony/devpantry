# Open-Source Icon Licensing & Attribution Guide

When building production web apps, mobile apps, SaaS dashboards, and commercial designs, icon licenses determine whether you can use the assets commercially without legal liability and whether visible attribution (e.g., "Icons made by X") is legally mandatory.

---

## 1. 100% Attribution-Free Open Source Licenses

The following licenses allow **unrestricted commercial and personal use with ZERO required attribution on your public website or app UI**:

### **MIT License**
- **Featured Libraries**: Tabler Icons, Heroicons, Iconoir, Phosphor Icons, Feather, Radix Icons, Octicons, Fluent UI System Icons, Bootstrap Icons.
- **Rules**: Free to use in commercial projects, websites, closed-source proprietary code, SaaS, and print. The license notice must remain within the source code/repository (no user-facing attribution needed).

### **ISC License**
- **Featured Libraries**: Lucide Icons.
- **Rules**: Functionally equivalent to MIT. Simple, permissive, and 100% attribution-free for end users.

### **Apache License 2.0**
- **Featured Libraries**: Google Material Symbols, Remix Icon.
- **Rules**: Free commercial use, distribution, and modification. Includes explicit patent grants. No public UI attribution required.

### **CC0 1.0 (Public Domain Dedication)**
- **Featured Libraries**: Simple Icons.
- **Rules**: Completely dedicated to the public domain. No copyright restrictions (note: brand logos are subject to trademark laws).

---

## 2. Licenses with Caveats / Attribution Traps

Be careful with other popular icon sets that are often mistaken for completely open-source:

| Library | License | Attribution Required? | Caveat |
| :--- | :--- | :---: | :--- |
| **Font Awesome Free** | CC BY 4.0 (Icons) / SIL OFL (Webfonts) | ⚠️ **YES** (for SVGs under CC BY 4.0) | Requires backlink/attribution if used under CC BY 4.0 unless using standard webfont format. |
| **Flaticon / Freepik** | Custom Freeware | ⚠️ **YES** | Mandatory visible attribution with backlinks for free tier. Cannot be redistributed. |
| **Noun Project (Free)** | CC BY 3.0 | ⚠️ **YES** | Mandatory credit under each icon or in project footer. |
| **Icons8 (Free)** | Custom Freeware | ⚠️ **YES** | Mandatory link back to Icons8 on every page with icons. |
